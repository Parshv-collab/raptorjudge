UI simplification
-----------------

The global shell now exposes only daily-use role links. Participants see Dashboard, My Events, and Browse. Judges see Judge Portal and My Assignments. Organizers see Dashboard, Events, and Judges. Admins see Dashboard, Events, Users, and Audit. Profile, settings, security, help, and logout are in the profile menu; mobile navigation is a hamburger menu.

The organizer dashboard now has one Create Event CTA, four stats, a simple event table, and a collapsed five-item activity section. The admin dashboard now has four stats, four quick links, and a recent audit list; user, event, audit, and settings views are query-link views rather than a persistent tab strip. The judge portal now presents only progress and an assigned queue; scoring moved to /judge/score/:id. Participant dashboard, public event, and gallery surfaces remain structurally light. Mobile overflow is protected globally, and reduced-motion and reduced-transparency preferences are respected.

Known gaps
----------

The source does not provide a complete judge invitation workflow, rubric locking, invite expiry/revocation, distributed rate limiting, external Sybil resistance, bulk import, a full database dump command, a versioned export schema, or a separate result-publication mutation. Live four-role browser acceptance and live Convex deployment acceptance require the self-hosted stack or a configured deployment and are not verifiable in this sandbox.
